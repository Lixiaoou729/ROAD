# ROAD: Modern Adversarial Training for Simple One-Step Distillation at Scale

**Xiaoou Li · Shan You · Tao Huang**

ROAD (Representation-grounded One-step Adversarial Distillation) trains diffusion generators to produce 1024×1024 images in a single forward pass, using adversarial training without classifier-free guidance at inference. This repository supports **SDXL** and **SD3.5-M**.

## Getting started

Use Python 3.11 and a CUDA environment. From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate
# Install the CUDA build of PyTorch 2.8.0 appropriate for your system first.
python -m pip install -e .
```

See the [PyTorch installation instructions](https://pytorch.org/get-started/previous-versions/). Diffusers, Transformers, and Accelerate versions are pinned in `pyproject.toml`.

Provision local base-model snapshots at `assets/sdxl` or `assets/sd35m`, and DINOv3 at `assets/dinov3-vitb16`. Prepare image/caption tar shards, index them, and cache text embeddings:

```bash
# SDXL: prepared 512×512 image/caption pairs
python -m road.prepare_data --shards data/sdxl/shards/*.tar --output data/sdxl/train.jsonl
python -m road.text_cache --family sdxl --base-model assets/sdxl --manifest data/sdxl/train.jsonl --output data/sdxl-text

# SD3.5-M: separate source RGB image/caption pairs
python -m road.prepare_data --shards data/sd35m/shards/*.tar --output data/sd35m/train.jsonl
python -m road.text_cache --family sd35m --base-model assets/sd35m --manifest data/sd35m/train.jsonl --output data/sd35m-text
```

See [data and assets](docs/data_and_assets.md) for model identities, image preparation, and text-cache storage requirements. Model assets and datasets are not included.

## Training

**SDXL — eight GPUs:**

```bash
torchrun --standalone --nproc_per_node=8 -m road.train_sdxl --config configs/sdxl.yaml
```

**SD3.5-M — two nodes with eight GPUs each:** set `NODE_RANK` to `0` or `1` on each node and `MASTER_ADDR` to node 0’s reachable address, then run on both nodes:

```bash
torchrun --nnodes=2 --nproc_per_node=8 --node_rank="$NODE_RANK" \
  --master_addr="$MASTER_ADDR" --master_port=29500 \
  -m road.train_sd35m --config configs/sd35m.yaml
```

Use shared assets and output storage across nodes. The recipes use global batches of 64 (SDXL) and 32 (SD3.5-M); adjust world size and accumulation together. See [training and checkpoints](docs/training.md) for resume and generator exports.

## Configuration

The two scientific ablation dimensions are **Mixing Refresh** and **Pooled R1 / Jacobian R1**:

```yaml
mixing:
  refresh_interval: 5000  # positive update interval; null for fixed mixing
regularization:
  type: jr1              # jr1 or pooled_r1
  gamma: 0.0075          # strength; SD3.5-M default: 0.00075; 0 disables R1
  lazy_interval: 16
```

Edit [the SDXL recipe](configs/sdxl.yaml) or [the SD3.5-M recipe](configs/sd35m.yaml). Further details are in the [training guide](docs/training.md).

## Inference and evaluation

Use a generator export from your own training run:

```bash
python -m road.infer --checkpoint outputs/sdxl/generator-0000500 \
  --base-model assets/sdxl --prompt 'A red panda reading a book' \
  --seed 10 --output outputs/example.png
```

For SD3.5-M, use its generator export and `assets/sd35m`. Choose new output paths.

For COCO evaluation, install `python -m pip install -e '.[eval]'`, prepare the COCO10K manifest, and configure local metric assets in `configs/evaluation_assets.example.json`:

```bash
python -m road.evaluation.generate --protocol coco10k --profile release_v2 \
  --checkpoint outputs/sdxl/generator-0000500 --base-model assets/sdxl \
  --prompts data/coco10k.jsonl --output outputs/coco-step500
python -m road.evaluation.coco --images outputs/coco-step500 \
  --prompts data/coco10k.jsonl --assets configs/evaluation_assets.example.json \
  --metrics fid --fid-cache outputs/fid-reference-cache --output outputs/fid-step500.json
```

The [evaluation guide](docs/evaluation.md) covers metrics, checkpoint selection, and official GenEval integration. Full pretrained CUDA training and paper-score reproduction remain unverified; see [validation status](docs/validation.md).
