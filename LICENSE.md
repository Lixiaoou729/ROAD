# Release licensing status

This directory is a private release-preparation work product. An overall public source license has **not** been assigned. No new blanket permission grant is made here. Existing upstream rights and notices remain applicable to inherited portions.

The research code was developed in a DMD2-derived repository whose root license is CC BY-NC-SA 4.0. Some components have ProjectedGAN/D2O ancestry with different notices. Copying a subset or rewriting its layout does not establish that the whole result can be relicensed under MIT or Apache-2.0.

Before public distribution, the owner must confirm provenance and authority, determine compatible terms for the integrated source and checkpoint releases, and replace this status document with the approved license while retaining all required notices. The license texts in `third_party/licenses/` are preserved source notices, not a declaration that each applies uniformly to the entire package. See `THIRD_PARTY_NOTICES.md`.

Pretrained model weights, derived checkpoints, training data and metric assets have separate terms and are not bundled.
